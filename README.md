# TRANSHUB — Controlled by AI Agents

Mobile-friendly prototype for the TRANSHUB digital transport ecosystem.

## Features
- Ride booking + live remaining km
- Logistics loads + bargaining
- Vehicle marketplace + stores
- Mechanic / e-garage
- Business & agent registration
- Messaging hub
- TRANSHUB Control + AI assistant
- Mobile bottom navigation

## How to run
Open `index.html` in a browser.
